# Datos del CSIRO para la cuenca Murray–Darling (para verificar los cálculos)

Página del proyecto (CSIRO, actualizada el 7 de febrero de 2025): https://www.csiro.au/en/research/natural-environment/natural-resources/Natural-capital-accounting/Murray-Darling-Basin

El proyecto lo financia el DCCEEW del Gobierno de Australia dentro de *Environmental Economic Accounting: A common national approach*. Los datos tienen licencia CC BY.
